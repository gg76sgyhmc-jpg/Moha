# طَيف · TAYF

موقع براند صوتيات كامل بصفحة واحدة — عربي (RTL) مع تبديل فوري للإنجليزية، وضع ليلي/نهاري،
وحركة مبنية على Canvas. بدون أي اعتماد خارجي: لا مكتبات، لا CDN، لا صور خارجية.

## المحتوى

| القسم | ماذا يفعل |
| --- | --- |
| الهيرو | طيف تردد حي على `<canvas>` يتفاعل مع حركة المؤشر، وعنوان يصعد كلمةً كلمة |
| الشريط المتحرك | مزايا المتجر في شريط لا نهائي يتوقف عند المرور عليه |
| المنتجات | ٦ منتجات بفلترة حسب الفئة، ميل ثلاثي الأبعاد عند المرور، وإضافة للسلة |
| اصنع سماعتك | مُهيّئ حقيقي: ٤ تشطيبات + ٣ إضافات، والسعر يُحتسب فوراً |
| التقنية | ٤ مزايا وعدّادات أرقام تتحرك عند الوصول إليها |
| الآراء | ٣ شهادات بتناوب تلقائي وتنقل يدوي |
| الأسئلة الشائعة | أكورديون بـ `grid-template-rows` (بدون قياس ارتفاع بجافاسكربت) |
| السلة | درج ينزلق من جهة القراءة، كميات، إجمالي، وحالة فراغ |

## البنية

```
src/index.template.html   المصدر الوحيد (HTML + CSS + JS)
assets/fonts/*.woff2      الخطوط: IBM Plex Sans Arabic · Sora · IBM Plex Mono
tools/build.py            يدمج الخطوط base64 وينتج المخرجات
index.html                صفحة مستقلة (GitHub Pages / تشغيل محلي)
dist/artifact.html        جزء بدون <html> للنشر كـ Artifact
```

عدّل `src/index.template.html` فقط، ثم:

```bash
python3 tools/build.py
```

الخطوط تُدمج كـ `data:` URI لأن سياسة أمان المحتوى في الـ Artifacts تمنع الطلبات
لأي مضيف خارجي، والخط الغائب يسقط بصمت إلى خط بديل.

## الثيم

مبني على ثيم **Tech Innovation**: أزرق كهربائي `#0066ff` وسماوي نيون `#00ffff`
على أرضية زرقاء-سوداء `#05070e`. الوضع الداكن هو الأصل، والنهاري يُعاد تعريفه
على مستوى التوكنات في ثلاث حالات: `:root` الداكن، ثم `prefers-color-scheme: light`
محميّاً بـ `:root:not([data-theme="dark"])`، ثم `:root[data-theme="light"]` ليفوز الزر
في الاتجاهين. أي لون يُعرَّف داخل media query فقط لن يظهر في الحالة غير المُوسَّمة.

**التباعد بين الأحرف:** الحروف العربية متصلة، و`letter-spacing` يفكّكها. لذلك التسميات
تستخدم `var(--track)` الذي يصبح `0` عندما `lang="ar"`، ويبقى `.16em` للإنجليزية.
