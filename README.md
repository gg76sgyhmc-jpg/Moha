# موقع مكتب عقار اليوم للعقارات

موقع تعريفي بصفحة واحدة لمكتب **عقار اليوم للعقارات** — الرياض، حي العقيق، شارع السليمانية.
مبني بـ HTML و CSS و JavaScript خالص، بلا أي مكتبات خارجية، ويعمل بفتح `index.html` مباشرة.

---

## التشغيل

```bash
# افتح الملف مباشرة
open index.html          # macOS
xdg-open index.html      # Linux

# أو عبر خادم محلي (مستحسن)
python3 -m http.server 8000
```

## البناء (نسخة بملف واحد)

```bash
node build.js
```

تُنتج:

| الملف | الوصف |
|---|---|
| `dist/index.html` | الصفحة كاملة مستقلة — الأنماط والسكربت والشعار مدمجة داخلها |
| `dist/artifact.html` | محتوى الصفحة فقط (للنشر داخل غلاف جاهز) |

---


## الهوية البصرية

اللوحة مستخرجة من شعار المكتب نفسه، لا من قالب جاهز:

| الرمز | الوضع الليلي | الوضع النهاري | المصدر |
|---|---|---|---|
| `--bg` | `#070530` | `#F7F3EA` | خلفية الشعار الكحلية `#06032A` |
| `--accent` | `#D9BA7B` | `#8A6A22` | ذهب الشعار |
| `--text` | `#F5F1E8` | `#100D2E` | — |

- **الخطوط:** Reem Kufi للعناوين (هندستها الكوفية تُجاري رمز الشعار المعيّن) + Tajawal للنصوص وواجهة الاستخدام.
- **لا زوايا حادة:** كل نصف قطر بين 14px و46px، والأزرار والشرائح دائرية بالكامل.
- **وضعان:** ليلي (الافتراضي، هوية المكتب) ونهاري، مع زر تبديل يحفظ الاختيار في `localStorage`.

## الحركة والتفاعل

- شبكة معينات متحركة على `<canvas>` في الواجهة، تستجيب لحركة المؤشر واللمس، وتُطلق حلقات عند الضغط.
- ظهور تدريجي للعناصر عبر `IntersectionObserver` بتأخير متدرج.
- عدّادات رقمية بأرقام عربية، وخيط ذهبي أعلى الصفحة يتتبّع نسبة التمرير.
- ميلان ثلاثي الأبعاد للبطاقات وأزرار مغناطيسية على الأجهزة ذات المؤشر فقط، وأثر لمس (ripple) على الجميع.
- كل مساحات اللمس ‏44px فأكثر، ولا يعتمد أي إجراء على التمرير بالمؤشر وحده.
- `prefers-reduced-motion` يوقف كل ذلك ويعرض الحالة النهائية مباشرة.

## ما يحتاج تحديثاً من المكتب

- **حسابات التواصل الاجتماعي:** لم يُعثر على حساب موثّق للمكتب، فلم يُوضع أي رابط.
  القالب جاهز في `index.html` تحت `<div class="social" hidden>` — ضع الرابط في `href` واحذف `hidden`.
- **رقم ترخيص الإعلان:** ورد الرقم `0121515` في نتائج البحث ولم يتأكد من صفحة رسمية، فلم يُنشر.
- نطاقات الأسعار وعدد الإعلانات تتغيّر؛ راجعها عند تحديث المعروض.
