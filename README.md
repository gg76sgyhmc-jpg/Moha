# موقع عنوان العقارية

موقع تعريفي لمكتب **عنوان العقارية** — خدمات عقارية ومقاولات، حي الكوثر، الخبر.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الموقع كامل في ملف واحد — الخطوط والشعار مدمجة داخله، ولا يحتاج إنترنت ولا أي ملفات خارجية |
| `assets/logo.png` | شعار المكتب (مقصوص الهوامش فقط، بدون أي تعديل على الشعار نفسه) |
| `assets/logo-original.png` | الشعار كما وصل، بهوامشه الأصلية |

## تعديل بيانات المكتب

كل البيانات القابلة للتغيير موجودة في مكان واحد: كتلة `BRAND` في أعلى `index.html`
(ابحث عن `✏️ بيانات المكتب`). عدّل القيمة واحفظ — الموقع يلتقطها تلقائيًا.

```js
phone:    "055 055 2987",
whatsapp: "966550552987",
email:    "arabianaddress.re@gmail.com",
hours:    "السبت – الخميس · 9 ص – 12 م  ثم  4 – 9 م · الجمعة إجازة",
rating:   null,      // متوسط تقييم قوقل، مثال: 4.9
reviews:  null,      // عدد المراجعات، مثال: 37
stats:    { years: 5, deals: null, clients: null },
testimonials: [ { name: "...", text: "...", stars: 5 } ],
photos:   [ { src: "assets/office-front.jpg", cap: "وصف الصورة" } ]
```

أي حقل فارغ (`""` أو `null`) يختفي قسمه من الصفحة تلقائيًا بدل أن يظهر ناقصًا —
قسم الأرقام وشارة التقييم ومعرض الصور كلها تظهر فقط عند تعبئة بياناتها.

> **ملاحظتان:** أوقات العمل قيمة افتراضية لمكاتب العقار وتحتاج تأكيدًا،
> ومتوسط التقييم وعدد المراجعات لم يُضافا بعد (المراجعات الستّ نفسها مضافة كما هي من قوقل).

### إضافة صور جديدة

الصور مدمجة داخل `index.html` كـ `data:` URI. لإضافة صورة:
ضعها في `assets/`، أضِف مسارها في `photos`، ثم شغّل:

```bash
python3 tools/inline-assets.py
```

## النشر

الملف مستقل بذاته، فيكفي رفع `index.html` على أي استضافة
(GitHub Pages، Netlify، Cloudflare Pages، أو أي سيرفر عادي).

لو أردت استخدام مسارات الصور في `photos`، ارفع مجلد `assets` بجانب `index.html`.

## ملاحظات تقنية

- الخطوط: Noto Kufi Arabic للعناوين (يعكس كوفية الشعار) + IBM Plex Sans Arabic للنصوص، مدمجة كـ `data:` URI.
- الصفحة تدعم الوضع الفاتح والليلي تلقائيًا، مع زر تبديل يدوي في الشريط العلوي.
- كل الرسومات أصلية (SVG خطي)، ولا توجد أي صورة مأخوذة من مكاتب أخرى.
- الحركات تتوقف تلقائيًا لمن فعّل `prefers-reduced-motion`.
