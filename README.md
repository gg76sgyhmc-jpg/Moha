# موقع مكتب لوامع للعقارات

موقع تعريفي من صفحة واحدة لمكتب **لوامع للعقارات** — الرياض، حي المصيف.
مبني بـ HTML و CSS و JavaScript خام، **بدون أي مكتبات خارجية ولا خطوات بناء**.
ارفع الملفات على أي استضافة وسيعمل مباشرة.

---

## ⚙️ التشغيل محلياً

```bash
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

> فتح `index.html` مباشرة من الملفات يعمل أيضاً، لكن التشغيل عبر خادم محلي أدق.

## 📝 تعديل بيانات التواصل

**كل بيانات التواصل في ملف واحد فقط:** [`assets/js/config.js`](assets/js/config.js)

```js
window.SITE_CONFIG = {
  phone: '966536611153',            // الرقم بالصيغة الدولية، أرقام فقط
  phoneDisplay: '+966 53 661 1153', // كما يظهر للزائر
  maps: 'https://maps.app.goo.gl/…',
  social: {
    x:         '',   // ← ضع الرابط هنا وستظهر الأيقونة تلقائياً
    instagram: '',
    snapchat:  '',
    tiktok:    '',
    youtube:   '',
    email:     ''
  }
};
```

### قاعدة مهمة
أي حقل تتركه فارغاً (`''`) **لا تظهر أيقونته إطلاقاً** — فلا توجد روابط معطّلة في الموقع.
أضف الرابط، احفظ الملف، حدّث الصفحة؛ تظهر الأيقونة فوراً في قسم «تواصل معنا» وفي الفوتر.

عند تغيير الرقم في `config.js` يتحدّث تلقائياً في:
أزرار الاتصال، أزرار واتساب، بطاقات التواصل، الفوتر، وشريط الجوال السفلي.
يبقى تحديثه يدوياً في نصّي العرض داخل `index.html` (`+966 53 661 1153`) وفي بيانات **JSON-LD**.

## 🖼️ إضافة صور حقيقية

الموقع يستخدم حالياً **رسوماً توضيحية SVG** مرسومة يدوياً (مبانٍ، أراضٍ، خريطة، أقواس نجدية)
بدل صور فوتوغرافية — لأنها تتكيّف مع الوضع الليلي، وسريعة التحميل، ولا تحتاج حقوق استخدام.

لاستبدالها بصور المكتب والعقارات الحقيقية:

1. ضع الصور في `assets/img/`.
2. في `index.html` استبدل كتلة `<svg>` داخل `.prop__media` بـ:
   ```html
   <img src="assets/img/property-1.webp" alt="وصف دقيق للعقار" width="400" height="260" loading="lazy" decoding="async">
   ```
3. استخدم صيغة **WebP** بعرض 800px تقريباً للحفاظ على سرعة الموقع.
4. احتفظ بنسبة `400:260` تقريباً حتى لا يتغيّر تخطيط البطاقات.

## ✨ التفاصيل التقنية

**الحركة**
حواف ناعمة في كل مكان (لا زوايا حادة)، منحنيات `cubic-bezier(.16,1,.3,1)`،
كشف تدريجي بالتمرير، بارالاكس منعّم بـ `lerp`، ميلان ثلاثي الأبعاد،
أزرار مغناطيسية، توهّج يتبع المؤشّر، وتأثير «لمعة» على الشعار — تحيّة لاسم المكتب.

**اللمس**
كل الأهداف ≥ 44×44 بكسل · سكة عروض بالسحب مع `scroll-snap` ·
شريط إجراءات ثابت أسفل شاشة الجوال · استجابة بصرية عند اللمس على البطاقات ·
دعم `env(safe-area-inset-*)` لشاشات الآيفون.

**الوصولية**
`lang="ar" dir="rtl"` · رابط تخطٍّ للمحتوى · حلقات تركيز واضحة ·
حصر التركيز داخل قائمة الجوال · `aria-label` لكل زر أيقوني ·
تباين نصوص ≥ 4.5:1 في الوضعين · احترام كامل لـ `prefers-reduced-motion`.

**الأداء والخصوصية**
لا مكتبات خارجية ولا أي طلب لطرف ثالث — الخط (Readex Pro المتغيّر) **مستضاف ذاتياً**
في `assets/fonts/` بحجم 54 كيلوبايت فقط للعربي واللاتيني معاً، فلا يُرسل زوّارك
أي بيانات إلى خوادم قوقل. SVG مضمّن بدل الصور · كل الحركة على `transform` و`opacity`
· `requestAnimationFrame` لكل ما يتعلق بالتمرير.

**التحقّق**
جرى فحص الموقع آلياً بمتصفّح Chromium على 5 عروض شاشة (360 / 390 / 768 / 1024 / 1440)
في الوضعين الليلي والنهاري: صفر أخطاء JavaScript، صفر روابط معطّلة، صفر تمرير أفقي،
صفر نص دون حدّ التباين 4.5:1، وكل أهداف اللمس ≥ 44×44 بكسل.

**تحسين محركات البحث**
وسوم Open Graph و Twitter Card · صورة مشاركة 1200×630 ·
بيانات منظّمة **JSON-LD** من نوع `RealEstateAgent` تشمل العنوان والهاتف والتقييم.

**الوضع الليلي**
يتبع إعداد النظام تلقائياً، مع زرّ تبديل يدوي يُحفظ في `localStorage`.

## 🎨 الهوية البصرية

**الشعار** ختم مؤسسي بحواف ناعمة يضمّ ثلاثة أبراج متدرّجة الارتفاع وخط أساس،
تعلوها لمعة رباعية — إشارة إلى اسم «لوامع». مرسوم بـ SVG داخل الصفحة
(`#mark-glyph`) فيتكيّف مع الوضعين ويظهر بأي دقة بلا تشويش.

**الألوان** أسود دافئ `#14120F` · ذهب `#C9A24A` · كريمي `#F7F4EE`.

**الخط** Readex Pro — خط متغيّر بأوزان 300 إلى 700، اختير لوضوح رسمه العربي.
ملاحظة: لا يُستخدم `letter-spacing` مع النصوص العربية إطلاقاً لأنه يفصل
الحروف المتّصلة ويكسر شكل الكلمة.
