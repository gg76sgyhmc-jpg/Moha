# رونق البن — صفحة الروابط والمنيو

صفحة واحدة (`index.html`) فيها شاشتان:

| الشاشة | الرابط | المحتوى |
|---|---|---|
| الروابط | `index.html` | الشعار، الحسابات، أرقام التواصل، الموقع، وزر المنيو |
| المنيو | `index.html#menu` | الأقسام والأسعار |

الصفحة كاملة بملف واحد — الخطوط والأيقونات مدمجة داخلها، فتفتح بدون إنترنت وبدون أي مكتبات خارجية. تدعم العربية من اليمين لليسار، والوضع الفاتح والداكن، وفيها زر لتبديل المظهر.

---

## ١) الشعار

ضعي ملف الشعار هنا بالضبط:

```
assets/logo.png
```

يفضّل PNG بخلفية شفافة، مربع، ٥١٢×٥١٢ أو أكبر. لم يُصمَّم أي شعار جديد — إذا لم يوجد الملف تعرض الصفحة اسم المقهى بخط الهوية مؤقتاً.

## ٢) تعديل المحتوى

كل النصوص والروابط والأسعار في مكان واحد: كائن `CONFIG` في نهاية `index.html`.

```js
phone:    "0138001234",        // رقم الهاتف
whatsapp: "966501234567",      // واتساب بصيغة دولية بدون +
```

الحسابات في `social`، وأزرار التواصل والطلب في `contact`. أي رابط قيمته `""` **يُخفى من الصفحة تلقائياً** (لأن `hideEmpty: true`)، فما يظهر إلا المؤكّد. الصقي الرابط في مكانه وبيبان مباشرة.

الموجود حالياً: تيك توك `@rawong_albon` والموقع على الخريطة. الباقي (انستقرام، سناب، إكس، الأرقام، التوصيل، التقييم) خانات جاهزة تنتظر روابطها.

## ٣) المنيو

> ⚠️ **الأصناف والأسعار الحالية غير معتمدة** — مكتوبة كمثال لشكل التصميم فقط، ويظهر فوقها شريط تنبيه في الصفحة. بعد إدخال منيو المحل الحقيقي غيّري `menuDraft: false` ليختفي الشريط.

كل قسم في `CONFIG.menu` بهذا الشكل:

```js
{
  id:"hot", ar:"الساخنة", en:"Hot",
  note:"سطر تعريفي اختياري تحت عنوان القسم",
  items:[
    { n:"اسم المشروب", d:"وصف قصير", p:"16", pin:"مميز",
      img:"assets/menu/latte.jpg" }
  ]
}
```

`p` السعر بالريال، `pin` وسم صغير اختياري (مميز / الأكثر طلباً / موسمي)، و`img` صورة الصنف — **صور المحل نفسه فقط**، تُوضع في `assets/menu/`. الصورة اختيارية ويضبط التصميم نفسه معها وبدونها. لحذف قسم احذفي الكائن كاملاً — شريط الأقسام يتولّد تلقائياً.

## ٤) ساعات العمل

```js
hours: {
  all:  { open: "06:30", close: "01:00" },
  label: "يومياً 6:30 ص — 1:00 ص"
}
```

تحسب الصفحة «مفتوح الآن / مغلق» بتوقيت الرياض وتحدّثها كل دقيقة، وتدعم الإغلاق بعد منتصف الليل.
