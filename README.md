# موقع مكتب إعمار الشعلة للخدمات العقارية

موقع تعريفي بصفحة واحدة لـ **مؤسسة مكتب إعمار الشعلة للخدمات العقارية** — الدمام، المنطقة الشرقية.

موقع ثابت (static) بدون أي مكتبات خارجية أو خطوة بناء: افتح `index.html` وسيعمل مباشرة.

---

## المحتويات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة كاملة (عربي، اتجاه RTL) |
| `assets/css/styles.css` | نظام التصميم بالكامل — الألوان، الحركة، التجاوب |
| `assets/css/fonts.css` | تعريفات الخطوط المستضافة محليًا |
| `assets/js/main.js` | كل التفاعلات (بدون مكتبات خارجية) |
| `assets/fonts/` | خطوط Amiri و Tajawal و Cinzel بصيغة woff2 |
| `assets/img/` | صور المكتب + الشعار + الأيقونة |

## تعديل بيانات التواصل

الأرقام مكتوبة مباشرة داخل `index.html` حتى تعمل حتى لو تعطّل الجافاسكربت.
للتغيير، ابحث واستبدل في `index.html`:

| الحالي | أين يظهر |
|---|---|
| `+966560420282` | روابط `tel:` (زر الاتصال) |
| `0560420282` | النص الظاهر للاتصال |
| `966561915272` | روابط `wa.me/` (واتساب) |
| `0561915272` | النص الظاهر للواتساب |

> رقم الواتساب في الرابط يُكتب بصيغة دولية **بدون** علامة `+` وبدون الصفر الأول:
> `0561915272` ← `966561915272`

يوجد أيضًا كائن `SITE` في أعلى `assets/js/main.js` يحتوي الأرقام واستعلام الخريطة —
حدّثه معها لتبقى الملفات متطابقة.

### رسالة الواتساب الجاهزة

روابط الواتساب تحتوي رسالة معدّة مسبقًا (`?text=...`) مُرمّزة بصيغة URL. لتغييرها،
رمّز النص الجديد ثم استبدل ما بعد `?text=`.

## <a id="social-links"></a>إضافة حسابات التواصل الاجتماعي

الموقع حاليًا يربط ما تم التحقق منه فقط: **واتساب، اتصال، خرائط جوجل، وملف منصة عقار**.
لم أضع حسابات إنستقرام أو سناب شات أو تويتر لأنني لم أجد حسابات مؤكدة تخص المكتب —
وإضافة روابط غير صحيحة أسوأ من عدم إضافتها.

لإضافة حساب، افتح `index.html` وابحث عن `<div class="socials">` في الفوتر، ثم أضف:

```html
<a href="https://instagram.com/USERNAME" target="_blank" rel="noopener" aria-label="إنستقرام">
  <svg viewBox="0 0 24 24" aria-hidden="true"><!-- أيقونة SVG --></svg>
</a>
```

وأضف الرابط أيضًا داخل مصفوفة `sameAs` في بيانات Schema.org أعلى الصفحة، ليتعرّف
عليه محرك البحث:

```json
"sameAs": ["https://sa.aqar.fm/user/690949", "https://instagram.com/USERNAME"]
```

## إضافة صور جديدة

الصور تُعرض بصيغتَي WebP و JPG معًا مع أحجام متعددة، ليختار المتصفح الأنسب.
لإضافة صورة جديدة، أنشئ النسخ المطلوبة:

```bash
python3 - <<'PY'
from PIL import Image
im = Image.open('صورتك.jpg').convert('RGB')
for w in (560, 828, 1400):
    if w > im.width: continue
    r = im.resize((w, round(im.height * w / im.width)), Image.LANCZOS)
    r.save(f'assets/img/الاسم-{w}.webp', 'WEBP', quality=82, method=6)
    r.save(f'assets/img/الاسم-{w}.jpg', 'JPEG', quality=84, optimize=True, progressive=True)
PY
```

ثم انسخ نمط `<picture>` الموجود في قسم `#office`، **ولا تنسَ** كتابة نص بديل
(`alt`) وصفي، وتحديد `width` و `height` لمنع اهتزاز الصفحة أثناء التحميل.

الملف `assets/img/office.png` هو النسخة الأصلية النظيفة من صورة المكتب (بعد إزالة
واجهة خرائط جوجل) — احتفظ بها لإعادة توليد الأحجام لاحقًا.

## نظام التصميم

الألوان مأخوذة من الشعار نفسه: تم أخذ عيّنة من الذهبي في الشعار (`#B1976C`)، ثم
بُني منه تدرّج كامل على نفس درجة اللون (H 37.4°، S 30.7%) بدرجات إضاءة مختلفة.

```
البيج (الأساسي)    #FBF7F0 → #E4D6C0
الأسود (الثانوي)   #14100D
الذهبي (لمسات)     #D8CBB6 · #B1976C · #786340 · #645235
```

**كل أزواج النص/الخلفية تحقق معيار WCAG AA (4.5:1 أو أعلى).** الذهبي الفاتح
مخصّص للزخرفة والحدود فقط — نصوص المتن تستخدم `--gold-ink` الأغمق.

- **الخطوط:** Amiri للعناوين · Tajawal للنصوص · Cinzel للأرقام والحروف اللاتينية
- **الحركة:** منحنيات `cubic-bezier` ناعمة، وكل الزوايا دائرية (`--r-xs` … `--r-2xl`)
- **الشعار:** رُسم كـ SVG متجهي من الشعار الأصلي، فيبقى حادًا عند أي حجم

### إمكانية الوصول والأداء

- ✅ صفر أخطاء في فحص axe-core (WCAG 2.1 AA) على الجوال وسطح المكتب
- ✅ يحترم `prefers-reduced-motion` — تُلغى كل الحركات ويظهر المحتوى مباشرة
- ✅ أهداف اللمس 44px فأكثر مع مسافات كافية بينها
- ✅ الخطوط مستضافة محليًا — لا اتصال بخوادم خارجية ولا تتبّع
- ✅ الخريطة لا تُحمّل إلا عند الضغط عليها (أسرع وأفضل للخصوصية)
- ✅ لا يوجد تمرير أفقي على أي مقاس (تم الاختبار على 390 و 820 و 1440 بكسل)

## النشر

الموقع ثابت بالكامل، لذا يمكن رفعه على أي استضافة.

### GitHub Pages

من إعدادات المستودع: **Settings → Pages → Source: Deploy from a branch**،
ثم اختر الفرع و `/ (root)`. سيظهر الموقع على:

```
https://gg76sgyhmc-jpg.github.io/moha/
```

> بعد ربط نطاق خاص، حدّث وسم `<link rel="canonical">` في `index.html`.

### تشغيل محلي

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
