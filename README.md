# قصدير — صفحة روابط + منيو

صفحة واحدة (Single page) تجمع روابط مطعم **قصدير** وحساباته وفروعه، ومعها المنيو بالأسعار.
كل شيء داخل ملف `index.html` واحد — الصور والخطوط مدمجة كـ data URI، فما يحتاج أي سيرفر أو إنترنت.

## البناء

```bash
python3 src/build.py      # يولّد qasdir.html بجانب السكربت
```

السكربت يقرأ:

- `src/assets/` — صور الأطباق واللوقو (مستخرج من صور المطعم نفسه)
- `src/fonts/`  — خطوط عربية مقتطعة (Rubik للعناوين، IBM Plex Sans Arabic للنصوص)

ويطلع ملف HTML واحد فيه كل شيء مدمج.

## مصادر البيانات

| المعلومة | المصدر |
|---|---|
| الأسعار والسعرات | صور منيو الفرع على خرائط قوقل — **مو** من تطبيقات التوصيل |
| صور الأطباق | صور المطعم على خرائط قوقل (تطبيقات التوصيل محجوبة عن السحب الآلي) |
| اللوقو | مستخرج من صورة كيس المطعم، ما فيه أي لوقو مصمم من جديد |
| الفروع والأرقام والتقييمات | خرائط قوقل |
| الحسابات | إنستقرام `@qasdir.sa` وتيك توك `@qasdirsa` |

## تعديل المحتوى

كل البيانات في أول `src/build.py`:

- `BRANCHES` — الفروع والأرقام وروابط الخرائط والتوصيل
- `MENU` — الأقسام والأصناف والأسعار والسعرات وصورة كل صنف

بعد أي تعديل، شغّل `python3 src/build.py` من جديد.
