# وبر كافيه · صفحة الروابط

صفحة روابط (link-in-bio) لـ **وبر كافيه — Wabr Cafe**، حي العقيق، الرياض.
ملف واحد مستقل: `index.html` — لا يحتاج بناء ولا خادم ولا أي مكتبة خارجية.
الشعار مدمج داخل الملف نفسه كـ data URI، والخطوط وحدها تُحمّل من Google Fonts.

---

## ⚠️ الشيء الوحيد الناقص: رقم التواصل

زرّا **واتساب** و**اتصال** جاهزان لكن الرقم غير مضاف — لم أجده منشوراً في أي
مصدر رسمي، ولم أرغب في اختراع رقم. افتح `index.html`، ابحث عن `CONFIG`
قرب بداية الـ `<script>`، وضع الرقم بصيغة دولية (أرقام فقط، بدون `+` ولا مسافات):

```js
const CONFIG = {
  phone: "9665XXXXXXXX",
  whatsappMessage: "السلام عليكم، أبغى أستفسر عن وبر كافيه"
};
```

بمجرد إضافته يعمل الزران تلقائياً، ويظهر الرقم منسّقاً تحت زر الاتصال،
والضغط المطوّل على الزر ينسخه.

## الحركة

- **تضاريس حيّة** خلف الصفحة: خطوط كنتور تُرسم بخوارزمية marching squares
  على canvas وتنساب ببطء — صدى لملمس ورق المنيو ولسطر «من الجبال نستلهم الهدوء».
- **دخول متتابع** للأقسام عند التحميل، بعد جاهزية الخطوط حتى لا يقفز النص.
- **تفاعل لمسي**: تموّج ينطلق من نقطة اللمس، انكماش خفيف عند الضغط،
  واهتزاز قصير على الأجهزة التي تدعمه.
- **شريط ارتفاع** على حافة الصفحة يتتبّع القسم الظاهر فعلياً.
- كل ذلك يتوقف تلقائياً مع `prefers-reduced-motion`.

## المنيو

منقول حرفياً عن المنيو المطبوع (٤ أقسام، ٢٨ صنفاً، السعرات والأسعار
وشارات الأكثر مبيعاً وملاحظة خلوّ الحلويات من الجلوتين). البيانات في مصفوفة
`MENU` داخل `<script>` — التعديل عليها يكفي لتحديث الصفحة، ولا يحتاج بناءً.

## البنية

```
index.html            الصفحة الجاهزة — هذه هي التي تُرفع
build/template.html   القالب المصدري (الصور فيه كعلامات {{...}})
build/artifact.html   نسخة بلا <html>/<head> للنشر كـ Artifact
build/build.py        يدمج الصور كـ data URI ويولّد المخرجين
assets/               الشعار بصيغه المختلفة + الأصل المنزّل
```

للتعديل على التصميم: عدّل `build/template.html` ثم `python3 build/build.py`.
للتعديل على المنيو أو الرقم فقط: عدّل `index.html` مباشرة (وانسخ التغيير
إلى القالب حتى لا يضيع عند البناء التالي).
