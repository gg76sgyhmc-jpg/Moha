# مؤسسة القطب البارد — الموقع الجديد

إعادة تصميم كاملة لموقع **مؤسسة القطب البارد (Cold Pole Est.)**، مؤسسة سعودية
متخصصة في تصنيع قنوات الهواء وأنظمة التكييف المركزي وأنظمة الحماية من الحريق،
تأسست في الخبر عام 2001.

الموقع صفحة واحدة بروابط داخلية (كما هو الموقع الأصلي)، بنسختين: العربية RTL
والإنجليزية LTR.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | النسخة العربية (RTL) — الصفحة الرئيسية |
| `en.html` | النسخة الإنجليزية (LTR) |
| `assets/css/styles.css` | نظام التصميم كاملاً (متغيرات، مكوّنات، استجابة) |
| `assets/js/main.js` | الترويسة اللاصقة، قائمة الجوال، الظهور التدريجي، العدّادات، النموذج |
| `assets/img/` | الشعار وصور الأعمال وشعارات العملاء |
| `assets/fonts/` | خط Tajawal (woff2، مقسّم عربي/لاتيني) |
| `build-preview.py` | يبني نسخة معاينة بملف واحد مستقل |
| `preview/coldpole-ar.html` | ناتج البناء — ملف واحد يعمل دون أي ملفات مرافقة |

## الهوية

اللوقو لم يُمس. الألوان مستخرجة من ملف الشعار نفسه بأخذ عيّنة من البكسلات:

| اللون | القيمة | مصدره في الشعار |
|---|---|---|
| الفحمي | `#303A3D` | الحلقة الداخلية |
| الأحمر | `#ED1C24` | القوس السفلي |
| السماوي | `#AADFF0` | القوس العلوي الأيمن |
| الذهبي | `#D6B453` | القوس العلوي الأيسر |

للنصوص والأزرار تُستخدم مشتقات أغمق (`--red-600`، `--sky-700`، `--gold-700`)
لضمان تباين لا يقل عن 4.5:1 مع الخلفية.

## قواعد التصميم

- **بدون زوايا حادة** — كل العناصر لها نصف قطر من `12px` للعناصر الصغيرة حتى
  `56px` للأقسام والصور، والأزرار بيضاوية بالكامل.
- ظلال ناعمة متدرجة الشدة، ومسافات واسعة (`64px`–`116px` بين الأقسام).
- خط **Tajawal** بأربعة أوزان، مضمّن محلياً — لا اعتماد على Google Fonts.
- الحركة تحترم `prefers-reduced-motion`، وحلقات التركيز ظاهرة للتنقل بلوحة المفاتيح.
- تخطيط منطقي (`inset-inline`, `padding-inline`) فتعمل النسختان العربية
  والإنجليزية من ملف CSS واحد.

## التشغيل محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

الخطوط تحتاج خادماً (لا تعمل عبر `file://` بسبب CORS).

## إعادة بناء ملف المعاينة

```bash
python3 build-preview.py
```

## ملاحظات تحتاج قراراً من المؤسسة

1. **عدد المشاريع:** الموقع الأصلي يذكر `2207` في النسخة العربية و`4,207` في
   الإنجليزية. اعتُمد `2207` في النسختين هنا — يلزم تأكيد الرقم الصحيح.
2. **نموذج التواصل** يفتح برنامج البريد لدى الزائر (`mailto:`). لاستقبال الرسائل
   مباشرة يلزم ربطه بخدمة نماذج أو نقطة نهاية على الخادم.
3. **حساب إنستقرام:** الموقع الأصلي يعرض أيقونته لكن الرابط يُحمَّل بجافاسكربت ولم
   يمكن استخراجه — لم يُضف حتى يُزوَّد الرابط الصحيح.
4. **دقة الصور:** صور الأعمال مأخوذة من الموقع الحالي وبعضها بدقة منخفضة
   (612×408). تزويد صور أعلى دقة سيرفع جودة العرض على الشاشات الحديثة.
5. **الملف التعريفي (PDF)** ما زال مرتبطاً بنسخته على الاستضافة الحالية.
