# إعمار وإستثمار العقارية — الموقع الرسمي

موقع تعريفي لمكتب **إعمار وإستثمار العقارية** (EMAAR & ESTETHMAAR) في حي الشراع بمدينة الخبر.
صفحة واحدة بالعربية (RTL)، بدون أي اعتماديات خارجية — لا CDN، لا خطوط بعيدة، لا تتبّع.

## المحتوى

| القسم | ماذا يحتوي |
|---|---|
| الواجهة | صورة المقرّ الحقيقية، رقم رخصة فال، أزرار اتصال/واتساب/اتجاهات |
| من نحن | نبذة المكتب ونطاق عمله |
| خدماتنا | بيع، شراء، تسويق، إدارة أملاك، استشارات وتقدير، متابعة إجراءات |
| العقارات | فلل، شقق، محلات تجارية، أراضٍ ومخططات |
| التقييم | ٤.٩ على Google مع روابط قراءة المراجعات وكتابة تقييم |
| المعرض | ٥ صور للمكتب مع عارض صور (Lightbox) |
| الموقع | خريطة، العنوان، رمز Plus، أوقات الدوام وحالة «مفتوح الآن» |
| تواصل | كل قنوات الاتصال + نموذج يرسل الطلب عبر واتساب |

**ملاحظة عن أوقات الدوام:** Google ينشر فترتَي الدوام أعلاه. عرضناها كما هي مع تنبيه

(٤.٩) ويربط الزائر بصفحة المراجعات الأصلية ليقرأها بنفسه.

## الشعار

الشعار **لم يُعدّل ولم يُعد رسمه**. استُخدم الشعار الرسمي للمكتب كما هو:

- `assets/img/logo-full.png` — الشعار الكامل (الرمز + الاسم العربي + الإنجليزي)،
  مصدره ملف المكتب الرسمي على «مكتمل»، أُزيلت خلفيته السوداء فقط ليظهر على أي سطح داكن.
- `assets/img/logo-mark.png` — رمز الأبراج الكوفي بدقة عالية، مقصوص من صورة اللوحة
  المضيئة للمكتب نفسها.

## التصميم

الهوية مستخرجة من لوحة المكتب المضيئة نفسها — ذهب دافئ على ليل الخليج:

```
--ink   #08060f      أرضية الصفحة (سماء الليل فوق اللوحة)
--gold  #dcb47c      ذهب حروف اللوحة المضيئة
--cream #f2ece2      أبيض دافئ من إضاءة المكتب الداخلية
```

الخطوط: **Noto Kufi Arabic** للعناوين (يجاري الرمز الكوفي في الشعار) و**IBM Plex Sans
Arabic** للنصوص والأرقام. الملفان مضمّنان محلياً في `assets/fonts/`.

الموقع بوضع داكن واحد مقصود — الشعار ذهبي على أسود، وأي أرضية فاتحة تكسره.

## البنية

```
index.html                 الصفحة
assets/css/styles.css      نظام التصميم كاملاً
assets/js/site.js          كل السلوك (بدون مكتبات)
assets/img/                الصور والخريطة والشعار
assets/fonts/              خطوط woff2 (عربي + لاتيني)
build/inline.py            يبني نسخة الملف الواحد
dist/                      ناتج البناء
```

## التشغيل

```bash
python3 -m http.server 8000     # ثم افتح http://localhost:8000
```

أو افتح `index.html` مباشرة — الموقع يعمل بلا خادم.

## بناء نسخة الملف الواحد

```bash
python3 build/inline.py
```

يُنتج:

- `dist/emaar-estethmaar.html` — ملف واحد مستقل (خطوط وصور مضمّنة كـ data URI)،
  يمكن إرساله بالبريد أو رفعه كما هو.
- `dist/artifact.html` — نفس المحتوى بلا وسوم الصفحة، للنشر كـ Artifact.

## النشر على GitHub Pages

من إعدادات المستودع ← Pages ← اختر الفرع والمجلد الجذر. الموقع ملفات ثابتة فقط.

## الخريطة

الخريطة صورة ثابتة مبنية من بلاطات **OpenStreetMap** حول إحداثيات المكتب، ثم أُعيد
تلوينها بألوان الهوية. الإسناد `© OpenStreetMap` ظاهر على الخريطة، والضغط عليها يفتح
موقع المكتب على خرائط Google.

## النموذج

لا يوجد خادم ولا تخزين للبيانات. عند الإرسال يتحقق النموذج من الاسم ورقم الجوال
السعودي، ثم يفتح محادثة واتساب جاهزة بنص الطلب — والزائر هو من يضغط إرسال.

## الوصولية

- تباين نص/خلفية يتجاوز 7:1 لكل الألوان المستخدمة
- كل الأزرار ≥ 44px، وحالة تركيز ظاهرة للوحة المفاتيح
- عارض الصور يدعم Esc والأسهم وحصر التركيز
- `prefers-reduced-motion` مُحترَم
- أيقونات SVG بـ `aria-hidden` وتسميات نصية للأزرار الأيقونية
